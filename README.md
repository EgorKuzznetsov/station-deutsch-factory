# 🇩🇪 Station Deutsch — автономная контент-фабрика

Каждый день сама придумывает, проверяет, рендерит и публикует **2 уникальных обучающих ролика — в 12:00 и 18:00 по Берлину —** (1080×1920, 10–30 с) в **YouTube Shorts** и **TikTok** с ненавязчивой рекламой бота **@station_deutsch_bot**. Ты управляешь всем с iPhone через мобильную панель. Компьютер не нужен, iPhone может быть выключен.

```
 Cloudflare Worker (бесплатно)                GitHub Actions (бесплатно)
 ┌─────────────────────────────┐   запуск    ┌──────────────────────────────────────┐
 │ Мобильная панель + пароль    │ ──────────► │ 1. выбор формата (с учётом статистики) │
 │ Расписание (cron каждые 5 мин)│            │ 2. задание из банка, без повторов      │
 │ OAuth YouTube / TikTok       │ ◄────────── │ 3. проверка: структура + LanguageTool  │
 │ KV: настройки, история, токены│  токены,   │ 4. рендер Pillow + FFmpeg → MP4        │
 └─────────────────────────────┘  история    │ 5. заголовок, описание, хештеги        │
                                             │ 6. YouTube API · TikTok API · Telegram │
                                             │ 7. история в state/ (git)              │
                                             └──────────────────────────────────────┘
```

## Что уже умеет

| | |
|---|---|
| **10 форматов** | перевод, найди ошибку, der/die/das, тест уровня A1→B2, A1 против B2, 5 слов по теме, разговорные фразы, вставь слово, типичные ошибки, мини-экзамен |
| **Банк заданий** | 246 существительных с артиклями и переводами (uk/ru), 64 задания с пропуском, 44 предложения с ошибками, 30 типичных ошибок, 42 фразы, 26 пар A1/B2. Это тысячи комбинаций |
| **Без повторов** | одинаковая комбинация не выходит никогда, каждое задание «отдыхает» 60 дней (настраивается) |
| **Проверка немецкого** | структурные проверки + все правильные предложения проходят через LanguageTool, а результат кэшируется |
| **Дизайн** | 5 тем (Midnight, Sunset, Mint, Berlin, Paper) или чередование, плавающие пятна, pop-анимации, таймер с пульсом, конфетти, переходы, цвета артиклей |
| **Звуки** | синтезированы кодом (свои, без чужих сэмплов): «вжух» на смене сцен, pop на появлении, тиканье таймера (последние 3 с — громче), аккорд и искры на правильном ответе, «бззз» на ошибке, «апгрейд» A1→B2, мелодия на финальной сцене. Вкл/выкл и громкость — в панели |
| **Реклама бота** | финальная сцена 3 с: иконка Telegram, @station_deutsch_bot, «3 дні повного доступу безкоштовно» (текст меняется в панели) |
| **Метаданные** | заголовок под формат, описание со ссылкой (YouTube), подпись для TikTok, 5 хештегов |
| **Аналитика** | ежедневно собирает просмотры, лайки, комментарии и репосты, после чего пересчитывает веса форматов: лучшие выходят чаще, остальные продолжают тестироваться |
| **Панель** | главная, история, статистика, настройки (расписание, темы, форматы, уровни, язык uk/ru, CTA, режимы публикации) |
| **Копия в Telegram** | каждый ролик приходит тебе с готовой подписью, его можно выложить вручную за 10 секунд |

## Сколько стоит: 0 €

- **GitHub Actions**: приватный репозиторий получает 2000 мин/мес бесплатно, фабрика тратит ~170 мин (2 ролика × ~2,5 мин × 30 дней + аналитика).
- **Cloudflare Workers + KV**: бесплатный тариф (100 000 запросов в день, панель использует < 1 %).
- **YouTube Data API, TikTok API, Telegram Bot API, LanguageTool**: бесплатно.
- **Gemini** (по желанию, для пополнения банка): бесплатный ключ Google AI Studio.

# Установка с iPhone (≈40 минут, один раз)

Всё делается в Safari. Рядом держи «Заметки», куда будешь временно копировать ключи.

## Шаг 1. GitHub-репозиторий

1. github.com → **+** → **New repository** → имя `station-deutsch-factory` → **Private** → отметь **Add a README** → **Create**.
2. Создай токен: аватар → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**.
   - Repository access: **Only select repositories** → `station-deutsch-factory`
   - Permissions → Repository: **Actions: Read and write**, **Contents: Read and write**, **Workflows: Read and write**
   - Expiration: 1 год. Скопируй токен (`github_pat_…`).
3. В репозитории: **Settings → Secrets and variables → Actions → New repository secret**:
   `GH_PAT` = токен из п. 2.
4. **Add file → Upload files** → выбери `station-deutsch-factory.zip` из «Файлов» → **Commit changes**.
5. **Add file → Create new file** → имя: `.github/workflows/unpack.yml` → вставь содержимое файла `unpack.yml` (я прислал его отдельно) → **Commit**.
6. Открой вкладку **Actions**: через ~30 с workflow «unpack» распакует проект и удалит сам себя. Обнови страницу и проверь, что появились папки `factory`, `worker` и `fonts`.

> Если Actions выключены: вкладка **Actions** → «I understand my workflows, go ahead and enable them».

## Шаг 2. Уведомления в Telegram (5 минут)

1. В Telegram открой **@BotFather** → `/newbot` → например `station_factory_bot`. Скопируй токен.
   (Отдельный бот нужен, чтобы не мешать основному @station_deutsch_bot.)
2. Напиши новому боту `/start`.
3. В Safari открой `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найди `"chat":{"id":123456789`. Это твой chat id.
4. В GitHub Secrets добавь `TG_BOT_TOKEN` и `TG_CHAT_ID`.

**Первый тест:** Actions → **produce** → **Run workflow**. Через 2–3 минуты в Telegram придёт первый ролик с подписью. Фабрика уже работает, осталось подключить панель и площадки.

## Шаг 3. Панель управления (Cloudflare, 10 минут)

1. dash.cloudflare.com → **Storage & Databases → KV → Create** → имя `factory`.
2. **Workers & Pages → Create → Create Worker** → имя `station-factory` → **Deploy** → **Edit code**.
   Удали весь код, вставь содержимое `worker/worker.js` (открой файл на GitHub → **Raw** → выдели всё → скопируй) → **Deploy**.
3. Worker → **Settings → Bindings → Add → KV namespace**: Variable name `KV`, namespace `factory`.
4. Worker → **Settings → Variables and Secrets → Add**:
   | Имя | Тип | Значение |
   |---|---|---|
   | `GH_REPO` | Text | `твой-логин/station-deutsch-factory` |
   | `ADMIN_PASSWORD` | Secret | пароль от панели |
   | `FACTORY_SECRET` | Secret | длинная случайная строка (≥ 32 символа) |
   | `GH_TOKEN` | Secret | токен из шага 1.2 |
5. Worker → **Settings → Trigger Events → Add → Cron Triggers** → `*/5 * * * *`.
6. В GitHub Secrets добавь `FACTORY_URL` = адрес воркера (`https://station-factory.<имя>.workers.dev`) и `FACTORY_SECRET` (то же значение, что в Cloudflare).
7. Открой адрес воркера → введи пароль → **Поделиться → На экран «Домой»**. Теперь панель открывается как приложение.

С этого момента расписание задаёт панель: по умолчанию **12:00 и 18:00** по Берлину. GitHub запускается в течение 5 минут после слота, рендер и загрузка занимают ещё 2–3 минуты, поэтому ролик выходит примерно в 12:03–12:08.

## Шаг 4. YouTube Shorts (10 минут)

1. console.cloud.google.com → создай проект `station-factory`.
2. **APIs & Services → Library** → **YouTube Data API v3** → **Enable**.
3. **OAuth consent screen** (Google Auth Platform): тип **External**, название, твоя почта. В Scopes ничего добавлять не нужно.
   **Важно:** в **Audience** нажми **Publish app** → *In production*. В режиме *Testing* Google отзывает доступ через 7 дней.
4. **Credentials → Create credentials → OAuth client ID → Web application**.
   Authorized redirect URI: `https://<твой-воркер>.workers.dev/oauth/youtube/callback`
5. Client ID и Secret добавь в Cloudflare как секреты `GOOGLE_CLIENT_ID` и `GOOGLE_CLIENT_SECRET`.
6. В панели: **Подключения → YouTube → Подключить**. Google покажет «приложение не проверено» → **Дополнительно → Перейти** (это твоё же приложение) → разреши доступ.

**Про приватную блокировку.** Раньше Google делал приватными все видео, загруженные через непроверенные API-проекты (созданные после июля 2020). В актуальной справке по `videos.insert` написано, что это ограничение больше не действует. Фабрика всё равно проверяет фактическую видимость после каждой загрузки. Если YouTube сделает ролик приватным, в истории появится статус «приватно (нужен аудит)» и тебе придёт сообщение в Telegram. Тогда нужно заполнить форму *YouTube API Services – Audit and Quota Extension Form* (бесплатно): это личный проект, который загружает собственный образовательный контент на свой канал.

## Шаг 5. TikTok (15 минут + ожидание проверки)

1. developers.tiktok.com → **Manage apps → Connect an app** (тип *Web*).
2. Заполни: иконка, категория *Education*, описание, **Terms of Service URL** = `https://<воркер>/terms`, **Privacy Policy URL** = `https://<воркер>/privacy`, Web/Desktop URL = адрес воркера.
3. **Add products**: **Login Kit** (Redirect URI: `https://<воркер>/oauth/tiktok/callback`) и **Content Posting API** (включи **Direct Post**).
4. **Scopes**: `user.info.basic`, `video.upload`, `video.publish`, `video.list`.
5. Client key и Client secret добавь в Cloudflare как `TIKTOK_CLIENT_KEY` и `TIKTOK_CLIENT_SECRET`.
6. Для теста до проверки: вкладка **Sandbox** → добавь свой аккаунт как *Target user*. Затем отправь приложение на проверку (**Submit for review**) с демо-видео: запиши экран, где ты входишь в панель, подключаешь TikTok и нажимаешь «Опубликовать в TikTok» у ролика в очереди.
7. После одобрения: **Подключения → TikTok → Подключить**.

**Как TikTok ограничивает автопубликацию (официальные правила):**

- Пока **Content Posting API** не прошёл отдельный **аудит**, Direct Post публикует только приватные ролики (`SELF_ONLY`), а сам аккаунт должен быть приватным. Аудит подаётся в кабинете разработчика.
- Поэтому по умолчанию включён режим **«Во входящие»** (inbox): ролик загружается черновиком, TikTok присылает уведомление, ты открываешь его и жмёшь «Опубликовать». Подпись с хештегами уже лежит в Telegram, её остаётся скопировать.
- После аудита переключи **Режим TikTok → «Сразу в ленту»**.
- Если аудитор потребует согласие на каждую публикацию, включи **«Одобрять каждый ролик вручную»**. Тогда ролики появляются в панели с данными аккаунта, видимостью и обязательным текстом *Music Usage Confirmation*, а публикуются одной кнопкой. Именно такой интерфейс TikTok требует в Content Sharing Guidelines.
- Включена честная пометка **«Your brand»** (`brand_organic_toggle`), потому что ролики продвигают твой собственный продукт. Правила TikTok требуют раскрывать коммерческий контент.

## Шаг 6 (по желанию). Пополнение банка через Gemini

aistudio.google.com → **Get API key** → добавь в GitHub Secrets `GEMINI_API_KEY`. Каждое воскресенье workflow **content** будет просить у Gemini новые задания. В банк попадут только те, что прошли структурные проверки и LanguageTool без замечаний. Они сохраняются в `factory/content/generated/` с пометкой `"src": "ai"`. Без ключа workflow просто перепроверяет весь банк.

# Как пользоваться

- **Главная:** сколько роликов вышло сегодня, переключатель вкл/выкл, кнопка «Создать видео сейчас» (с выбором формата), очередь TikTok, подключения, последние запуски GitHub.
- **История:** каждый ролик со статусами YouTube и TikTok, ссылкой и просмотрами.
- **Статистика:** всего роликов и просмотров, вес и медиана каждого формата.
- **Настройки:** язык роликов (uk/ru), бот, текст рекламы, время публикаций, тема, время на ответ (3–8 с), уровни, вес и включение каждого формата, видимость и режимы публикации.

### Посмотреть ролик без публикации
Actions → **produce** → Run workflow → формат на выбор. Либо локально: `python -m factory.main preview --format article --theme mint`. Видео появится в `out/`.

### Добавить свои задания
Отредактируй файлы в `factory/content/` прямо в GitHub (значок карандаша):
- `nouns.txt`: `артикль|Слово|українською|по-русски|A1|тема`
- `fill.json`: первый вариант в `"o"` всегда правильный, остальные перемешаются сами
- `errors.json`: `bad` и `fix` должны дословно встречаться в `wrong` и `right`

После правок запусти **content**: он проверит всё через LanguageTool и выведет отчёт в Summary.

### Резервный режим без панели
Если Cloudflare недоступен, создай в GitHub **Settings → Variables** переменную `USE_GH_SCHEDULE = 1`. Тогда `produce.yml` запускается по своему cron (время в UTC). Резервный cron срабатывает в 12:00 и 18:00 по Берлину и сам учитывает переход на летнее время. Для YouTube без панели добавь секреты `YT_CLIENT_ID`, `YT_CLIENT_SECRET` и `YT_REFRESH_TOKEN`.

# Правила площадок: что уже учтено

- **Только официальные API** (YouTube Data API v3, TikTok Content Posting API). Никаких ботов-кликеров, эмуляции браузера и неофициальных библиотек.
- **Оригинальность:** каждый ролик собирается заново из уникальной комбинации заданий, темы и анимации. Повторы исключены, нет чужих видео, музыки и изображений. Все звуки синтезированы кодом, поэтому проблем с авторскими правами нет; трендовый звук при желании можно добавить в приложении TikTok вручную.
- **Без ИИ-видео:** всё нарисовано программно, поэтому `is_aigc=false` и `containsSyntheticMedia=false` честные.
- **Коммерческий контент:** в TikTok стоит метка «Your brand», реклама в ролике занимает одну финальную сцену.
- **Лимиты:** 2 ролика в день. Это далеко от квоты YouTube (100 загрузок в день) и обычного лимита Direct Post (~15 постов в день на автора).
- **Токены:** хранятся в Cloudflare KV и GitHub Secrets, не попадают в код и логи. Панель защищена паролем и подписанной cookie (HMAC, HttpOnly, Secure), API фабрики закрыт отдельным секретом.
- **YouTube «шаблонный контент»:** для монетизации YouTube требует ценность и разнообразие. Здесь их дают 10 форматов, 5 тем и уникальные задания. Если планируешь монетизацию, время от времени добавляй и свои ролики.

# Если что-то не работает

| Симптом | Что сделать |
|---|---|
| В Telegram ничего не пришло | Actions → последний запуск **produce** → открыть лог. Проверь `TG_BOT_TOKEN`, `TG_CHAT_ID` и то, что ты написал боту `/start` |
| Панель: «GitHub 401/404» | Проверь `GH_TOKEN` (права Actions RW) и `GH_REPO` (`логин/репо`) |
| Расписание не запускается | Worker → Settings → Trigger Events: должен быть `*/5 * * * *`. Фабрика включена в панели? |
| YouTube: `not_connected` | Подключи YouTube в панели. Если через 7 дней снова отключился, приложение в Google осталось в режиме *Testing* (шаг 4.3) |
| TikTok: `unaudited_client_can_only_post_to_private_accounts` | Режим «Сразу в ленту» до аудита не работает → включи «Во входящие» |
| TikTok: `scope_not_authorized` | Добавь scope в приложении TikTok и переподключи аккаунт |
| «Не удалось собрать уникальное задание» | Включено слишком мало форматов или уровней, либо слишком большой cooldown. Включи больше форматов или добавь задания |

# Структура проекта

```
factory/
  main.py          команды: produce · publish · analytics · validate · preview
  generators.py    10 форматов, выбор без повторов, взвешенный выбор формата
  render.py        видеодвижок (Pillow → FFmpeg H.264, 30 fps, 1080×1920)
  themes.py        дизайн-темы
  checker.py       проверки + LanguageTool + кэш
  meta.py          заголовки, описания, хештеги
  analytics.py     статистика и веса форматов
  refill.py        (опц.) пополнение банка через Gemini
  audio.py         синтез звуковых эффектов (numpy → WAV)
  i18n.py          тексты на экране (uk/ru)
  publish/         youtube.py · tiktok.py · telegram.py
  content/         банк заданий (проверенный вручную)
worker/worker.js   панель управления + расписание + OAuth (Cloudflare)
.github/workflows/ produce · publish · analytics · content
state/             история, использованные задания, кэш проверок, статистика
fonts/             Inter (лицензия SIL OFL)
config.json        настройки по умолчанию (панель их переопределяет)
```
